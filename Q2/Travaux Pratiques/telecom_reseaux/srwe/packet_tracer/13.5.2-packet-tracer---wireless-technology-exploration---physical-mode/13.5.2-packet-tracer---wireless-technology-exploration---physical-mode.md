# Packet Tracer – Wireless Technology Exploration (Physical Mode)

> **Objectif** : Explorer un réseau sans fil en mode physique (PTPM), ajouter un LAP dans une salle de réunion, connecter un Coffee Shop via réseau cellulaire, et configurer un réseau domestique avec routeur sans fil et modem câble.

> ⚠️ **Note** : Exercice en **Physical Mode** — non noté. Pas de CLI, uniquement des manipulations physiques et GUI dans Packet Tracer.

---

## Topologie — 5 emplacements dans Home City

```
Corporate Office ──┐
                   ├── WAN (câbles fibre/cuivre) ── Central Office (CO)
Branch Office ─────┘                                    ├── Cell Towers 0-5
                                                        └── CMTS ── Home Office (câble modem)
Coffee Shop ── Cell Tower (coaxial) ── CO Server
```

| Site | Infrastructure sans fil |
|------|------------------------|
| Corporate Office | WLC + 6 LAPs (C1–C6) |
| Branch Office | WLC + 6 LAPs (B1–B6) |
| Central Office | Réseau cellulaire (Cell Towers 0–5) |
| Coffee Shop | Zone morte cellulaire → à corriger |
| Home Office | Routeur sans fil + modem câble |

## Partie 1 : Explorer le réseau sans fil

### Étape 1 – Explorer la topologie

Naviguer dans les différents emplacements en mode physique.

**Réponse — comment les bureaux sont-ils connectés ?**  
Les bureaux (Corporate, Branch, CO) sont reliés entre eux par des câbles **Gigabit Ethernet** ou des liens **série** via les interfaces G2/0 et G3/0 des routeurs. Ce sont des liens point-à-point (/30).

**Réponse — comment les LAPs sont-ils connectés au réseau ?**  
Les LAPs sont connectés par câble **Copper Straight-Through** au switch du local technique, qui est lui-même connecté au WLC. Le WLC gère tous les LAPs de façon centralisée via le protocole CAPWAP.

**Réponse — comment les antennes cellulaires sont-elles connectées au CO Server ?**  
Les Cell Towers sont connectées au Central Office Server via des câbles **coaxiaux** (interface Coaxial sur les tours et sur le serveur CO).

### Étape 2 – Vérifier la connectivité

**Corporate Office → Wiring Closet → Laptop → Desktop → Command Prompt**

```
ping 192.168.2.10
! → réussit ✅ (Branch Office Server)

ping 192.168.5.2
! → réussit ✅ (CO backbone)
```

**Smartphone (près du CO) → Desktop → Command Prompt**

```
ping 172.16.1.1
! → réussit ✅ (connexion cellulaire CO)

ping 192.168.1.10
! → réussit ✅ (Corporate Office Server)
```

**Réponse — connexions physiques entre Smartphone1 et le Corporate Server :**  
Smartphone → signal **cellulaire radio** → Cell Tower → câble **coaxial** → CO Server → câble **Gigabit** → CO Router → WAN → Corporate Router → Corporate Server.

## Partie 2 : Ajouter un LAP dans la salle de réunion (Branch Office)

La salle de réunion (boardroom) est en zone morte WiFi — aucun LAP ne la couvre.

### Étape 1 – Installer le nouveau LAP

1. Naviguer dans **Branch Office**.
2. Glisser l'**access point** depuis l'Inventory Shelf vers le **Boardroom**.
3. Cliquer sur le nouvel AP → **Modules** → glisser un **ACCESS_POINT_POWER_ADAPTER** vers le port power (à côté du bouton Reset).
4. **Config tab → GLOBAL Settings** → renommer : `LAP-B6`
5. **INTERFACE → Dot11Radio0** → Coverage Range : `75.00 meters`
6. Fermer la fenêtre — la couverture WiFi apparaît dans la salle.

### Étape 2 – Câbler le LAP au switch

**Bottom Toolbar → Connections → Copper Straight-Through**

Connecter : **LAP-B6 GigabitEthernet0 → Branch Switch Fa0/22** (via le rack dans le local technique)

### Étape 3 – Vérifier la connectivité

**Boardroom Laptop → Desktop → IP Configuration**  
→ doit recevoir une IP DHCP (toggler DHCP/Static si nécessaire + Fast Forward)

```
ping 192.168.2.1
! → réussit ✅ (gateway Branch)

ping 192.168.1.10
! → réussit ✅ (Corporate Server)
```

## Partie 3 : Ajouter la connectivité cellulaire au Coffee Shop

Le Coffee Shop est dans une **zone morte cellulaire** — la Cell Tower voisine n'est pas connectée au CO.

### Étape 1 – Connecter la Cell Tower manquante

**Bottom Toolbar → Connections → Coaxial cable**

Connecter : **Cell Tower Coaxial0 → Central Office Server Coaxial0/3** (via Central Office Wiring Closet)

### Étape 2 – Tethering Bluetooth Smartphone → Laptop

1. **Smartphone → Config → 3G/4G Cell1** → vérifier IP reçue (DHCP Refresh si nécessaire)
2. **Smartphone → Settings** → vérifier gateway et DNS
3. **Smartphone → Cellular Tethering** → activer **Bluetooth**
4. **Smartphone → INTERFACE → Bluetooth** → Port Status : **On**, Discoverable : activé
5. **Laptop (Coffee Shop) → Desktop → Bluetooth** → Port Status : **On**
6. **Laptop → Discover** → Smartphone1 apparaît → **Pair** → **Yes**
7. **Laptop → sélectionner Smartphone1 → Tether**

> 💡 Rapprocher le smartphone et le laptop si le Bluetooth ne détecte pas.

Après tethering, le laptop reçoit une IP valide via le réseau cellulaire.

```
ping 172.16.1.1
! → réussit ✅ (gateway cellulaire)

ping 192.168.1.10
! → réussit ✅ (Corporate Server)
```

## Partie 4 : Configurer le réseau du Home Office

Le Home Office est nouveau — aucun réseau n'est configuré. Il faut connecter le modem câble au CO via coaxial et configurer le routeur sans fil.

### Étape 1 – Câbler les équipements

**Câble Copper Straight-Through :**  
**Cable Modem Port 1 → Wireless Router Internet port**

**Câble Coaxial :**  
**Cable Modem Port 0 → CO Wiring Closet → CMTS → Coaxial7**

### Étape 2 – Configurer le routeur sans fil

**Home Office → Wireless Router → GUI tab → Setup**

Vérifier / configurer :

| Paramètre | Valeur |
|-----------|--------|
| Internet Connection | Automatic DHCP |
| Router IP | `192.168.0.1` |
| Subnet Mask | `255.255.255.0` |
| DHCP | Enabled |
| Starting IP | `192.168.0.100` |
| Max Users | `50` |

**Status tab** → vérifier IP Internet reçue du CO (IP Renew si nécessaire).

**Wireless tab → 2.4 GHz :**
- SSID : `homesweethome`
- **Save Settings**

**Wireless Security → 2.4 GHz :**
- Security Mode : `WPA2-Personal`
- Passphrase : `mySecureNet`
- **Save Settings**

### Étape 3 – Connecter le laptop

**Home Office Laptop → Config → INTERFACE → Wireless0**

| Paramètre | Valeur |
|-----------|--------|
| SSID | `homesweethome` |
| Authentication | `WPA2-PSK` |
| PSK Pass Phrase | `mySecureNet` |

Le laptop reçoit une IP DHCP dans `192.168.0.100+`.

```
ping 192.168.6.1
! → réussit ✅ (CO Router G1/0)

ping 192.168.1.10
! → réussit ✅ (Corporate Server)

ping 192.168.2.10
! → réussit ✅ (Branch Server)
```

## Questions de réflexion

**1. Quel bénéfice global les technologies sans fil apportent-elles ?**  
Mobilité totale — les utilisateurs peuvent travailler depuis n'importe où sans contrainte de câblage physique. Réduction des coûts d'infrastructure et flexibilité de déploiement.

**2. Quelle forme de réseau sans fil est la plus bénéfique ?**  
Dépend du contexte : WiFi (WLC + LAPs) pour les bureaux (débit élevé, sécurité WPA2-Enterprise), 4G/5G pour la mobilité externe. La combinaison des deux offre la meilleure couverture.

**3. Bénéfices par profil :**

| Profil | Bénéfice principal |
|--------|--------------------|
| Étudiant | Accès aux ressources depuis n'importe quel endroit du campus |
| Commercial | Connectivité cellulaire pour travailler en déplacement chez les clients |
| Ingénieur R&D | WiFi entreprise sécurisé (WPA2-Enterprise) pour accéder aux ressources internes |
| Dirigeant | Connectivité unifiée depuis le bureau, la salle de réunion ou en déplacement |
