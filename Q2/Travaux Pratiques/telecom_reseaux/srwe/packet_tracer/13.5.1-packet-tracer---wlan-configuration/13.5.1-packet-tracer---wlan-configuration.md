# Packet Tracer – WLAN Configuration

> **Objectif** : Exercice de synthèse WLAN — configurer un routeur sans fil domestique et un WLC entreprise avec WPA2-PSK et WPA2-Enterprise, puis connecter tous les hôtes et vérifier la connectivité.

---

## Partie 1 : Configurer le routeur sans fil domestique

**Browser → `192.168.0.1` → admin/admin** (adresse par défaut avant modification)

### Étape 1 – Paramètres DHCP et réseau

**Setup → Basic Setup → Network Setup**

| Paramètre | Valeur |
|-----------|--------|
| Router IP | `192.168.6.1` |
| Subnet Mask | `255.255.255.224` (/27) |
| DHCP Start IP | `192.168.6.3` |
| Max DHCP Users | `20` |
| Static DNS | `10.100.100.252` |

**Internet Setup** → **Automatic Configuration – DHCP** (port Internet reçoit son IP via DHCP)

Cliquer **Save Settings**.

**Réponse — quelle IP l'interface Internet a-t-elle reçue ?**  
Une IP dans le réseau fourni par le FAI simulé dans Packet Tracer (DHCP upstream).

### Étape 2 – Configurer le SSID et le canal

**Wireless → Basic Wireless Settings → 2.4 GHz**

| Paramètre | Valeur |
|-----------|--------|
| SSID | `HomeSSID` |
| Channel | `6` |
| SSID Broadcast | **Enabled** *(visible par tous les clients)* |

Cliquer **Save Settings**.

### Étape 3 – Configurer la sécurité et le mot de passe admin

**Wireless → Wireless Security → 2.4 GHz**

| Paramètre | Valeur |
|-----------|--------|
| Security Mode | `WPA2 Personal` |
| Encryption | `AES` |
| Passphrase | `Cisco123` |

Cliquer **Save Settings**.

**Administration → Management** → changer le Router Password → `Cisco123` → **Save Settings**  
Se reconnecter avec `admin` / `Cisco123`.

### Étape 4 – Connecter les clients domestiques

**Laptop → Desktop → PC Wireless → Connect → Refresh**  
Sélectionner `HomeSSID` → `Cisco123` → **Connect**

**Tablet PC / Smartphone → Config → Wireless0**

| Paramètre | Valeur |
|-----------|--------|
| SSID | `HomeSSID` |
| Authentication | `WPA2-PSK` |
| PSK Pass Phrase | `Cisco123` |

Vérifier :
```
! Depuis chaque hôte → Command Prompt
ping 203.0.113.78   ! → ✅ (Web Server)
! Browser → http://www.netacad.pt (ou URL du Web Server)  → ✅
```

## Partie 2 : Configurer le WLC entreprise

**Enterprise Admin → Web Browser → `https://192.168.100.254`**  
Login : `admin` / `Cisco123`

### Étape 1 – Créer les interfaces VLAN

**Controller → Interfaces → New**

**Interface WLAN 2 :**

| Paramètre | Valeur |
|-----------|--------|
| Interface Name | `WLAN 2` |
| VLAN ID | `2` |
| Port Number | `1` |
| IP Address | `192.168.2.254` |
| Netmask | `255.255.255.0` |
| Gateway | `192.168.2.1` |
| Primary DHCP Server | `192.168.2.1` |

Cliquer **Apply** → **OK** → **Save Configuration**.

**Interface WLAN 5 :**

| Paramètre | Valeur |
|-----------|--------|
| Interface Name | `WLAN 5` |
| VLAN ID | `5` |
| Port Number | `1` |
| IP Address | `192.168.5.254` |
| Netmask | `255.255.255.0` |
| Gateway | `192.168.5.1` |
| Primary DHCP Server | `192.168.5.1` |

Cliquer **Apply** → **OK** → **Save Configuration**.

### Étape 2 – Configurer le DHCP scope interne

**Controller → Internal DHCP Server → DHCP Scope → New**

| Paramètre | Valeur |
|-----------|--------|
| Scope Name | `management` |
| Pool Start | `192.168.100.235` |
| Pool End | `192.168.100.245` |
| Network | `192.168.100.0` |
| Netmask | `255.255.255.0` |
| Default Routers | `192.168.100.1` |
| Status | **Enabled** |

Cliquer **Apply** → **Save Configuration**.

### Étape 3 – Configurer RADIUS et SNMP

**RADIUS — Security → New :**

| Paramètre | Valeur |
|-----------|--------|
| Server Index | `1` |
| Server IP | `10.6.0.254` |
| Shared Secret | `RadiusPW` |

Cliquer **Apply**.

**SNMP — Management → SNMP → Trap Receivers → New :**

| Paramètre | Valeur |
|-----------|--------|
| Community Name | `WLAN` |
| IP Address | `10.6.0.254` |

Cliquer **Apply**.

### Étape 4 – Créer les WLANs

**WLANs → Create New → Go**

**WLAN 1 — WPA2-PSK (SSID-2) :**

| Paramètre | Valeur |
|-----------|--------|
| Profile Name | `Wireless VLAN 2` |
| SSID | `SSID-2` |
| ID | `2` |
| Status | **Enabled** ✅ |
| Interface | `WLAN 2` |
| Security Layer 2 | `WPA+WPA2` → WPA2 Policy → **PSK** |
| Passphrase | `Cisco123` |
| FlexConnect | Local Switching + Local Auth activés |

Cliquer **Apply**.

**WLAN 2 — WPA2-Enterprise (SSID-5) :**

| Paramètre | Valeur |
|-----------|--------|
| Profile Name | `Wireless VLAN 5` |
| SSID | `SSID-5` |
| ID | `5` |
| Status | **Enabled** ✅ |
| Interface | `WLAN 5` |
| Security Layer 2 | `WPA+WPA2` → WPA2 Policy → **802.1X** |
| AAA Server 1 | `10.6.0.254` (RADIUS) |
| FlexConnect | Local Switching + Local Auth activés |

Cliquer **Apply**.

### Étape 5 – Connecter les hôtes entreprise

**Wireless Host 1 → SSID-2 (WPA2-PSK) :**

**PC Wireless → Connect → Refresh**  
Sélectionner `SSID-2` → `Cisco123` → **Connect**

**Wireless Host 2 → SSID-5 (WPA2-Enterprise) :**

**PC Wireless → Profiles → New**

| Paramètre | Valeur |
|-----------|--------|
| Profile Name | `Enterprise VLAN5` |
| SSID | `SSID-5` → Advanced Setup |
| Network | DHCP |
| Security | `WPA2-Enterprise` |
| Login | `userWLAN5` |
| Password | `userW5pass` |

**Save** → sélectionner le profil → **Connect to Network**

### Étape 6 – Vérifier la connectivité

```
! Depuis Wireless Host 1 et 2 → Command Prompt
ping 203.0.113.78    ! → ✅ (Web Server)

! Browser → http://www.netacad.pt  → ✅
```

## Script complet (toutes les manipulations dans l'ordre)

```
! ══════════════════════════════════════════════
! Cet exercice se fait entièrement via GUI web
! ══════════════════════════════════════════════


! ─── PARTIE 1 : Home Wireless Router ──────────

! Browser > 192.168.0.1 > admin/admin
! Setup > Basic Setup :
!   Router IP    : 192.168.6.1 / 255.255.255.224
!   DHCP Start   : 192.168.6.3
!   Max Users    : 20
!   DNS Static   : 10.100.100.252
!   Internet     : Automatic DHCP
! → Save Settings

! Wireless > Basic : SSID=HomeSSID, Canal=6, Broadcast=Enabled
! Wireless > Security : WPA2 Personal, AES, Cisco123
! Administration > Management : Password=Cisco123
! → Save Settings → reconnecter admin/Cisco123

! Laptop > PC Wireless > Connect > HomeSSID / Cisco123
! Tablet/Smartphone > Config > Wireless0 :
!   SSID=HomeSSID, WPA2-PSK, Cisco123

! Vérification :
ping 203.0.113.78   ! → ✅


! ─── PARTIE 2 : WLC entreprise ────────────────

! Enterprise Admin > https://192.168.100.254 > admin/Cisco123

! Controller > Interfaces > New (x2) :
!   WLAN 2 : IP=192.168.2.254, VLAN=2, GW=192.168.2.1, DHCP=192.168.2.1
!   WLAN 5 : IP=192.168.5.254, VLAN=5, GW=192.168.5.1, DHCP=192.168.5.1
! → Apply > OK > Save Configuration

! Controller > Internal DHCP > Scope > New :
!   Name=management, Start=.235, End=.245
!   Network=192.168.100.0, GW=192.168.100.1, Enabled
! → Apply > Save Configuration

! Security > RADIUS > New :
!   IP=10.6.0.254, Secret=RadiusPW
! → Apply

! Management > SNMP > Trap Receivers > New :
!   Community=WLAN, IP=10.6.0.254
! → Apply

! WLANs > Create New (x2) :
! SSID-2 : Profile=Wireless VLAN 2, ID=2, Interface=WLAN 2
!   Enabled, WPA2-PSK=Cisco123, FlexConnect ON
! SSID-5 : Profile=Wireless VLAN 5, ID=5, Interface=WLAN 5
!   Enabled, WPA2-Enterprise 802.1X, RADIUS=10.6.0.254, FlexConnect ON

! Wireless Host 1 > PC Wireless > Connect > SSID-2 / Cisco123
! Wireless Host 2 > PC Wireless > Profiles > New :
!   SSID-5, WPA2-Enterprise, userWLAN5/userW5pass > Connect

! Vérification :
ping 203.0.113.78   ! → ✅ sur tous les hôtes
```
