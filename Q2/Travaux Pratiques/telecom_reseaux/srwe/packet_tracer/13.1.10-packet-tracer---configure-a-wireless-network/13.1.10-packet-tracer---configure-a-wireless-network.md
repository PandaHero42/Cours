# Packet Tracer – Configure a Wireless Network

> **Objectif** : Configurer un routeur sans fil (WR), connecter des clients filaires et sans fil, ajouter un point d'accès (AP) pour étendre la couverture, et modifier les paramètres administratifs.

> ⚠️ **Note** : Cet exercice se fait principalement via l'**interface graphique web** du routeur sans fil (GUI à 192.168.0.1). Très peu de commandes CLI sont utilisées.

---

## Topologie

```
Internet (209.165.200.226) ── WR (port Internet : 209.165.200.225)
                                  ├── Admin (filaire, F0)
                                  ├── Laptop1 (WiFi 2.4GHz, SSID : aCompany)
                                  ├── Laptop2 (WiFi 2.4GHz, SSID : aCompany)
                                  └── AP (filaire Port0) ── Laptop3 (WiFi via AP)
```

---

## Partie 1 : Connexion au routeur sans fil

### Étape 1 – Câbler Admin au WR

Dans l'UI Packet Tracer : **Connections → Copper Straight-Through**  
Connecter **Admin FastEthernet0 → WR port Ethernet disponible**

### Étape 2 – Configurer Admin en DHCP

**Admin → Desktop → IP Configuration → DHCP**

Admin reçoit automatiquement une IP dans la plage `192.168.0.100` – `.149` (DHCP du WR).

**Réponses attendues :**
- IP : `192.168.0.100` (ou autre dans la plage)
- Masque : `255.255.255.0`
- Gateway : `192.168.0.1`

### Étape 3 – Accéder à l'interface web du WR

**Admin → Desktop → Web Browser → `192.168.0.1`**  
Login : `admin` / Password : `admin`

**Réponse — l'IP d'Admin est-elle dans la plage DHCP ?**  
Oui — le serveur DHCP du WR distribue des adresses en `192.168.0.0/24` à partir de `.100`. Admin reçoit une adresse dans cette plage car il est connecté au LAN du WR.

### Étape 4 – Configurer le port Internet du WR

**Basic Setup → Internet Setup → Static IP**

| Champ | Valeur |
|-------|--------|
| Internet IP Address | `209.165.200.225` |
| Subnet Mask | `255.255.255.252` |
| Default Gateway | `209.165.200.226` |
| DNS Server | `209.165.201.1` |

Cliquer **Save Settings**.

Vérifier : **Admin → Web Browser → `www.cisco.pka`** → doit s'ouvrir ✅

## Partie 2 : Configurer les paramètres sans fil

### Étape 1 – Configurer le SSID

**WR GUI → Wireless → Basic Wireless Settings**

| Paramètre | Valeur |
|-----------|--------|
| Network Name (SSID) 2.4 GHz | `aCompany` *(sensible à la casse)* |
| Standard Channel | `6 - 2.437GHz` |
| 5 GHz | **Désactiver** les deux fréquences 5 GHz |

Cliquer **Save Settings**.

### Étape 2 – Configurer la sécurité sans fil

**WR GUI → Wireless → Wireless Security → 2.4 GHz**

| Paramètre | Valeur |
|-----------|--------|
| Security Mode | `WPA2 Personal` |
| Encryption | `AES` (défaut) |
| Passphrase | `Cisco123!` |

Cliquer **Save Settings**.

### Étape 3 – Connecter Laptop1 et Laptop2

**Laptop → Desktop → PC Wireless → Connect → Refresh**

1. Sélectionner le réseau `aCompany`
2. Entrer la passphrase : `Cisco123!`
3. Cliquer **Connect**
4. Vérifier : **Web Browser → `www.cisco.pka`** ✅

Répéter pour **Laptop2**.

## Partie 3 : Ajouter un Access Point

### Étape 1 – Configurer l'AP

Câbler : **AP Port0 → WR port Ethernet disponible** (Copper Straight-Through)

**AP → Config → INTERFACE → Port 1**

| Paramètre | Valeur |
|-----------|--------|
| SSID | `aCompany` |
| Security | `WPA2-PSK` |
| Pass Phrase | `Cisco123!` |
| Encryption Type | `AES` (défaut) |

### Étape 2 – Connecter Laptop3 via l'AP

**Laptop3 → Desktop → PC Wireless → Connect → Refresh**

1. Sélectionner `aCompany` avec le **signal le plus fort (Channel 1)** → c'est l'AP
2. Cliquer **Connect**
3. Vérifier : **Web Browser → `www.cisco.pka`** ✅

## Partie 4 : Tâches administratives

### Étape 1 – Changer le mot de passe d'administration du WR

**WR GUI → Administration → Management**

| Paramètre | Valeur |
|-----------|--------|
| Router Password | `cisco` |

Cliquer **Save Settings** → se reconnecter avec `admin` / `cisco`.

### Étape 2 – Changer la plage DHCP du WR

**WR GUI → Setup → Basic Setup → Network Setup**

Changer l'IP du routeur de `192.168.0.1` → `192.168.50.1`
- IP Start : `.100` (inchangé)
- Nombre d'IPs : `50` (inchangé)
- DNS Server : `209.165.201.1`

Cliquer **Save Settings**.

**Réponse — pourquoi le navigateur affiche "Request Timeout" ?**  
Parce que l'adresse IP du WR a changé (`192.168.0.1` → `192.168.50.1`). Le navigateur tente toujours d'atteindre l'ancienne adresse qui n'existe plus. Il faut renouveler l'IP d'Admin et se reconnecter à `192.168.50.1`.

Forcer le renouvellement DHCP sur Admin :

```
! Admin → Desktop → Command Prompt
ipconfig /renew
```

**Réponse — nouvelle IP d'Admin :**  
Une adresse dans `192.168.50.100` – `.149` avec gateway `192.168.50.1`.

Vérifier sur tous les laptops : `ipconfig /renew` puis **`www.cisco.pka`** ✅

**Réponse — pourquoi Laptop1 est connecté à l'AP plutôt qu'au WR ?**  
Après le renouvellement DHCP, Laptop1 s'est reconnecté au point d'accès le plus proche physiquement (l'AP) qui diffuse le même SSID `aCompany`. Le client WiFi choisit automatiquement le signal le plus fort.
