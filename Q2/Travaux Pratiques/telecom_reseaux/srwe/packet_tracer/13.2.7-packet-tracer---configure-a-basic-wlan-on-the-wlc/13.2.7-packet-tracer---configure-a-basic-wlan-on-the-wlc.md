# Packet Tracer – Configure a Basic WLAN on the WLC

> **Objectif** : Explorer l'interface d'un Wireless LAN Controller (WLC), créer un nouveau WLAN, le sécuriser en WPA2-PSK, et connecter un client sans fil via un Lightweight Access Point (LAP).

> ⚠️ **Note** : Cet exercice se fait entièrement via l'**interface web HTTPS du WLC**. Aucune commande CLI n'est utilisée.

---

## Topologie

| Device        | Interface    | Adresse IP           |
|---------------|--------------|----------------------|
| R-1           | G0/0         | 172.31.1.1/24        |
| R-1           | G0/0/1.5     | 192.168.5.1/24       |
| R-1           | G0/0/1.200   | 192.168.200.1/24     |
| SW-1          | VLAN 200     | 192.168.200.100/24   |
| LAP-1         | G0           | DHCP                 |
| WLC-1         | Management   | 192.168.200.254/24   |
| Server        | NIC          | 172.31.1.254/24      |
| Admin PC      | NIC          | 192.168.200.200/24   |
| Wireless Host | Wireless NIC | DHCP                 |

### Concepts clés

| Terme | Définition |
|-------|-----------|
| **WLC** | Wireless LAN Controller — gère centralement tous les APs |
| **LAP** | Lightweight Access Point — AP sans intelligence propre, contrôlé par le WLC |
| **SSID** | Service Set Identifier — nom du réseau WiFi visible par les clients |
| **Profile Name** | Nom interne du WLAN dans le WLC (différent du SSID) |
| **WLAN-5** | Interface VLAN préconfigurée sur le WLC pour ce WLAN |
| **FlexConnect** | Mode permettant au LAP de commuter le trafic localement même si le lien WLC est perdu |

## Partie 1 : Surveiller le WLC

### Connexion à l'interface web

1. Attendre que STP converge (tous les liens verts) — cliquer **Fast Forward Time** si nécessaire.
2. **Admin PC → Desktop → Web Browser**
3. URL : `https://192.168.200.254` *(HTTPS obligatoire)*
4. Login : `admin` / Password : `Cisco123`

### Explorer l'écran Monitor Summary

**Réponse — que peut-on apprendre sur l'écran Monitor Summary ?**  
L'écran affiche un résumé global du WLC : nombre d'APs connectés, clients associés, utilisation des interfaces, alertes actives, statut général du réseau sans fil.

**Réponse — le WLC est-il connecté à un AP ?**  
Oui — LAP-1 apparaît dans la section **Access Point Summary**.

### Explorer l'écran All APs

Cliquer **Detail** à côté de *All APs*.

**Réponse — informations disponibles sur les APs :**  
Nom du LAP, adresse IP, modèle, statut (enregistré/non enregistré), nombre de clients associés, canal utilisé, puissance de transmission.

## Partie 2 : Créer un WLAN

### Étape 1 – Créer et activer le WLAN

**WLC GUI → WLANs → Create New → Go**

| Paramètre | Valeur |
|-----------|--------|
| Profile Name | `Floor 2 Employees` |
| SSID | `SSID-5` |
| ID | `5` |

Cliquer **Apply**.

Dans l'écran d'édition du WLAN :
- Cocher **Enabled** *(étape critique souvent oubliée)*
- **Interface/Interface Group** → sélectionner `WLAN-5`

Aller dans l'onglet **Advanced** :
- Activer **FlexConnect Local Switching**
- Activer **FlexConnect Local Auth**

Cliquer **Apply**.

### Étape 2 – Sécuriser le WLAN (WPA2-PSK)

**WLANs Edit → Security → Layer 2**

| Paramètre | Valeur |
|-----------|--------|
| Layer 2 Security | `WPA+WPA2` |
| WPA2 Policy | ✅ Coché |
| Authentication Key Management | `PSK` activé |
| Pre-Shared Key | `Cisco123` |

Cliquer **Apply**.

### Étape 3 – Vérifier les paramètres

Cliquer **Back** → retour à l'écran WLANs.

**Réponse — informations disponibles sur l'écran WLANs :**  
ID du WLAN, Profile Name, SSID, statut (enabled/disabled), interface VLAN associée, type de sécurité configuré.

---

## Partie 3 : Connecter un hôte au WLAN

### Étape 1 – Connecter Wireless Host

**Wireless Host → Desktop → PC Wireless → Connect**

1. Attendre que `SSID-5` apparaisse dans la liste (Fast Forward si nécessaire)
2. Sélectionner `SSID-5` → **Connect**
3. Entrer la passphrase : `Cisco123`
4. Vérifier dans **Link Information** → message de connexion réussie ✅
5. Cliquer **More Information** pour voir les détails de la connexion

### Étape 2 – Vérifier l'adressage IP

**Wireless Host → Desktop → IP Configuration**

Vérifier que Wireless Host a reçu une IP DHCP valide (pas une adresse APIPA `169.254.x.x`).  
Si APIPA → cliquer **Fast Forward Time** plusieurs fois.

### Étape 3 – Vérifier la connectivité

```
! Wireless Host → Desktop → Command Prompt
ping 192.168.5.1
! → réussit ✅ (gateway WLAN, subinterface R-1)

ping 172.31.1.254
! → réussit ✅ (Server)
```

---

> ⚠️ **Points d'attention** :
> - Toujours utiliser **HTTPS** pour accéder au WLC (pas HTTP).
> - Ne pas oublier de cocher **Enabled** sur le WLAN — c'est l'erreur la plus fréquente.
> - Cliquer **Apply** après chaque modification, sinon les changements ne sont pas sauvegardés.
> - LAP = Lightweight AP — il n'a pas de config locale, tout est géré par le WLC.
