# Packet Tracer – Configure IPv4 and IPv6 Static and Default Routes

> **Objectif** : Configurer des routes statiques, routes par défaut, routes flottantes (floating static) et routes hôtes en IPv4 et IPv6 pour assurer la connectivité et la redondance via deux ISPs.

---

## Topologie

| Device | Interface | IPv4 | IPv6 |
|--------|-----------|------|------|
| Edge_Router | S0/0/0 | 10.10.10.2/30 | 2001:db8:a:1::2/64 |
| Edge_Router | S0/0/1 | 10.10.10.6/30 | 2001:db8:a:2::2/64 |
| Edge_Router | G0/0 | 192.168.10.17/28 | 2001:db8:1:10::1/64 |
| Edge_Router | G0/1 | 192.168.11.33/27 | 2001:db8:1:11::1/64 |
| ISP1 | S0/0/0 | 10.10.10.1/30 | 2001:db8:a:1::1/64 |
| ISP1 | G0/0 | 198.0.0.1/24 | 2001:db8:f:f::1/64 |
| ISP2 | S0/0/1 | 10.10.10.5/30 | 2001:db8:a:2::1/64 |
| ISP2 | G0/0 | 198.0.0.2/24 | 2001:db8:f:f::2/64 |
| Customer Server | NIC | 198.0.0.10 | 2001:db8:f:f::10 |

### Architecture de routage

```
LAN1 (192.168.10.16/28) ─── Edge_Router ─── S0/0/0 ─── ISP1 ─── Internet
LAN2 (192.168.11.32/27) ─┘                └── S0/0/1 ─── ISP2 ─┘
                                                         (redondance)
```

### Concepts clés

| Terme | Définition |
|-------|-----------|
| **Route statique** | Route configurée manuellement — ne change pas automatiquement |
| **Route par défaut** | `0.0.0.0/0` — utilisée quand aucune route spécifique ne correspond |
| **Floating static** | Route statique avec une AD élevée — utilisée seulement si la route principale disparaît |
| **Route hôte** | Route vers une IP précise — masque /32 (IPv4) ou /128 (IPv6) |
| **AD** | Administrative Distance — plus la valeur est faible, plus la route est préférée |

---

## Partie 1 : Routes par défaut IPv4 sur Edge_Router

### Route principale vers ISP1 (AD par défaut = 1)

Route directement connectée via l'interface S0/0/0.

```
Edge_Router# configure terminal

Edge_Router(config)# ip route 0.0.0.0 0.0.0.0 s0/0/0
! → tout le trafic sans route spécifique passe par ISP1
```

### Route flottante vers ISP2 (AD = 5)

La AD de 5 est supérieure à 1 → cette route ne sera utilisée que si la route principale (via ISP1) disparaît.

```
Edge_Router(config)# ip route 0.0.0.0 0.0.0.0 s0/0/1 5
! → route de secours via ISP2, activée seulement si ISP1 est down
```

---

## Partie 2 : Routes par défaut IPv6 sur Edge_Router

### Route principale vers ISP1 (next hop)

En IPv6, on préfère utiliser le **next hop** (adresse du voisin) plutôt que l'interface directement connectée.

```
Edge_Router(config)# ipv6 route ::/0 2001:db8:a:1::1
! → next hop = ISP1 S0/0/0 côté ISP1
```

### Route flottante vers ISP2 (AD = 5)

```
Edge_Router(config)# ipv6 route ::/0 2001:db8:a:2::1 5
! → next hop = ISP2 S0/0/1 côté ISP2, secours si ISP1 down

Edge_Router(config)# end
```

## Partie 3 : Routes IPv4 sur ISP1 vers les LANs internes

ISP1 ne connaît pas les réseaux LAN derrière Edge_Router — il faut lui ajouter des routes statiques.

### Réseaux LAN à joindre

- **LAN1** : `192.168.10.16/28` (réseau de `192.168.10.17/28`, masque `255.255.255.240`)
- **LAN2** : `192.168.11.32/27` (réseau de `192.168.11.33/27`, masque `255.255.255.224`)

### Routes principales vers Edge_Router (next hop 10.10.10.2)

```
ISP1# configure terminal

ISP1(config)# ip route 192.168.10.16 255.255.255.240 10.10.10.2
! → LAN1 via Edge_Router

ISP1(config)# ip route 192.168.11.32 255.255.255.224 10.10.10.2
! → LAN2 via Edge_Router
```

### Routes flottantes via ISP2 (directement connecté, AD = 5)

Si le lien ISP1→Edge_Router tombe, ISP1 peut passer par ISP2 pour joindre les LANs.  
ISP1 et ISP2 partagent le réseau `198.0.0.0/24` via leurs interfaces G0/0.

```
ISP1(config)# ip route 192.168.10.16 255.255.255.240 g0/0 5
! → LAN1 via ISP2 (G0/0 = interface vers réseau partagé avec ISP2)

ISP1(config)# ip route 192.168.11.32 255.255.255.224 g0/0 5
! → LAN2 via ISP2

ISP1(config)# end
```

## Partie 4 : Routes IPv6 sur ISP1 vers les LANs internes

### Routes principales vers Edge_Router (next hop 2001:db8:a:1::2)

```
ISP1# configure terminal

ISP1(config)# ipv6 route 2001:db8:1:10::/64 2001:db8:a:1::2
! → LAN1 IPv6 via Edge_Router

ISP1(config)# ipv6 route 2001:db8:1:11::/64 2001:db8:a:1::2
! → LAN2 IPv6 via Edge_Router
```

### Routes flottantes via ISP2 (next hop 2001:db8:f:f::2, AD = 5)

```
ISP1(config)# ipv6 route 2001:db8:1:10::/64 2001:db8:f:f::2 5
! → LAN1 IPv6 via ISP2 si ISP1→Edge down

ISP1(config)# ipv6 route 2001:db8:1:11::/64 2001:db8:f:f::2 5
! → LAN2 IPv6 via ISP2

ISP1(config)# end
```

## Partie 5 : Routes hôtes vers le Customer Server

Une route hôte cible une **adresse IP précise** avec un masque `/32` (IPv4) ou `/128` (IPv6).  
Utilisée ici pour optimiser le chemin vers un serveur client spécifique (`198.0.0.10`).

### Routes hôtes IPv4 sur Edge_Router

```
Edge_Router# configure terminal

Edge_Router(config)# ip route 198.0.0.10 255.255.255.255 s0/0/0
! → route hôte vers Customer Server via ISP1 (directement connecté)

Edge_Router(config)# ip route 198.0.0.10 255.255.255.255 s0/0/1 5
! → route hôte flottante via ISP2, AD=5
```

### Routes hôtes IPv6 sur Edge_Router

```
Edge_Router(config)# ipv6 route 2001:db8:f:f::10/128 2001:db8:a:1::1
! → route hôte IPv6 via ISP1 (next hop)

Edge_Router(config)# ipv6 route 2001:db8:f:f::10/128 2001:db8:a:2::1 5
! → route hôte IPv6 flottante via ISP2, AD=5

Edge_Router(config)# end
```

## Vérification

```
Edge_Router# show ip route
! → vérifier routes 0.0.0.0/0 (x2 : une active, une flottante)
! → vérifier routes hôtes 198.0.0.10/32

Edge_Router# show ipv6 route
! → vérifier ::/0 (x2)
! → vérifier 2001:db8:f:f::10/128

ISP1# show ip route
! → vérifier 192.168.10.16/28 et 192.168.11.32/27

! Depuis PC-A
ping 198.0.0.10   ! → ✅ (Customer Server via ISP1)
```

---

## Résumé des commandes clés

| Commande | Rôle |
|----------|------|
| `ip route 0.0.0.0 0.0.0.0 <int/next-hop>` | Route par défaut IPv4 |
| `ip route 0.0.0.0 0.0.0.0 <int/next-hop> 5` | Route par défaut flottante (AD=5) |
| `ipv6 route ::/0 <next-hop>` | Route par défaut IPv6 |
| `ipv6 route ::/0 <next-hop> 5` | Route par défaut IPv6 flottante |
| `ip route <réseau> <masque> <next-hop>` | Route statique vers un réseau |
| `ip route <host> 255.255.255.255 <int>` | Route hôte IPv4 (/32) |
| `ipv6 route <host>/128 <next-hop>` | Route hôte IPv6 (/128) |
| `show ip route` | Table de routage IPv4 |
| `show ipv6 route` | Table de routage IPv6 |

---

> ⚠️ **Floating static route** : la route avec AD=5 n'apparaît **pas** dans la table de routage tant que la route principale (AD=1) est active — elle est en attente. Elle devient visible et active uniquement si la route principale disparaît (lien down).

## Script complet (toutes les commandes dans l'ordre)

```
! ══════════════════════════════════════════════
! ─── Edge_Router ──────────────────────────────
! ══════════════════════════════════════════════

    enable

        configure terminal

            ! ─── Global Config ───────────────

            ! Routes par défaut IPv4
            ip route 0.0.0.0 0.0.0.0 s0/0/0
            ! → primaire via ISP1 (AD=1 par défaut)
            ip route 0.0.0.0 0.0.0.0 s0/0/1 5
            ! → flottante via ISP2 (AD=5)

            ! Routes par défaut IPv6
            ipv6 route ::/0 2001:db8:a:1::1
            ! → primaire via ISP1
            ipv6 route ::/0 2001:db8:a:2::1 5
            ! → flottante via ISP2

            ! Routes hôtes IPv4 vers Customer Server
            ip route 198.0.0.10 255.255.255.255 s0/0/0
            ip route 198.0.0.10 255.255.255.255 s0/0/1 5

            ! Routes hôtes IPv6 vers Customer Server
            ipv6 route 2001:db8:f:f::10/128 2001:db8:a:1::1
            ipv6 route 2001:db8:f:f::10/128 2001:db8:a:2::1 5

            end

        show ip route
        show ipv6 route


! ══════════════════════════════════════════════
! ─── ISP1 ─────────────────────────────────────
! ══════════════════════════════════════════════

    enable

        configure terminal

            ! ─── Global Config ───────────────

            ! Routes IPv4 vers LANs internes
            ip route 192.168.10.16 255.255.255.240 10.10.10.2
            ! → LAN1 via Edge_Router (next hop)
            ip route 192.168.11.32 255.255.255.224 10.10.10.2
            ! → LAN2 via Edge_Router

            ! Routes flottantes via ISP2
            ip route 192.168.10.16 255.255.255.240 g0/0 5
            ip route 192.168.11.32 255.255.255.224 g0/0 5

            ! Routes IPv6 vers LANs internes
            ipv6 route 2001:db8:1:10::/64 2001:db8:a:1::2
            ! → LAN1 via Edge_Router
            ipv6 route 2001:db8:1:11::/64 2001:db8:a:1::2
            ! → LAN2 via Edge_Router

            ! Routes IPv6 flottantes via ISP2
            ipv6 route 2001:db8:1:10::/64 2001:db8:f:f::2 5
            ipv6 route 2001:db8:1:11::/64 2001:db8:f:f::2 5

            end

        show ip route
        show ipv6 route


! ─── Vérification finale ──────────────────────
! PC-A > ping 198.0.0.10             → ✅ (Customer Server)
! PC-B > ping 2001:db8:f:f::10      → ✅ (Customer Server IPv6)
```
