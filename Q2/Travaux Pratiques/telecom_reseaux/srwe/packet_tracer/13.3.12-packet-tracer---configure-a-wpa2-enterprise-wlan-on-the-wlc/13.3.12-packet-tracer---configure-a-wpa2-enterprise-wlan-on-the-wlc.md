# Packet Tracer – Configure a WPA2 Enterprise WLAN on the WLC

> **Objectif** : Configurer un WLAN WPA2-Enterprise sur un WLC avec authentification RADIUS (802.1X), créer une interface VLAN dynamique, configurer un scope DHCP interne, et ajouter SNMP.

> ⚠️ **Note** : Cet exercice se fait entièrement via l'**interface web HTTPS du WLC**. Aucune commande CLI n'est utilisée.

---

## Topologie

| Device             | Interface  | Adresse IP           |
|--------------------|------------|----------------------|
| R-1                | G0/0/0.5   | 192.168.5.1/24       |
| R-1                | G0/0/0.200 | 192.168.200.1/24     |
| R-1                | G0/0/1     | 172.31.1.1/24        |
| SW-1               | VLAN 200   | 192.168.200.100/24   |
| LAP-1              | G0         | DHCP                 |
| WLC-1              | Management | 192.168.200.254/24   |
| RADIUS/SNMP Server | NIC        | 172.31.1.254/24      |
| Admin PC           | NIC        | 192.168.200.200/24   |

### WPA2-PSK vs WPA2-Enterprise

| | WPA2-PSK | WPA2-Enterprise |
|--|----------|-----------------|
| Authentification | Clé partagée identique pour tous | Compte individuel username/password via RADIUS |
| Scalabilité | Faible — une clé compromise = tout le réseau compromis | Élevée — révocation par compte individuel |
| Traçabilité | Aucune | Logs par utilisateur sur le serveur RADIUS |
| Usage | PME, réseau domestique | Entreprise |
| Protocole | PSK | 802.1X / EAP |

## Partie 1 : Créer le WLAN

### Étape 1 – Connexion au WLC

**Admin PC → Desktop → Web Browser**  
URL : `https://192.168.200.254`  
Login : `admin` / `Cisco123`

### Étape 2 – Créer une interface VLAN dynamique (WLAN-5)

Chaque WLAN sur le WLC nécessite une **interface dynamique** associée à un VLAN — c'est l'équivalent des sous-interfaces sur un routeur Router-on-a-Stick.

**WLC GUI → Controller → Interfaces → New**

| Paramètre | Valeur |
|-----------|--------|
| Interface Name | `WLAN-5` |
| VLAN ID | `5` |

Cliquer **Apply**, puis configurer :

| Paramètre | Valeur |
|-----------|--------|
| Physical Port Number | `1` |
| IP Address | `192.168.5.254` |
| Netmask | `255.255.255.0` |
| Gateway | `192.168.5.1` |
| Primary DHCP Server | `192.168.5.1` |

Cliquer **Apply** → **OK** → **Save Configuration**.

> 💡 Le DHCP server pointe vers `192.168.5.1` (R-1) — le WLC transfère les requêtes DHCP des clients WLAN vers ce serveur.

### Étape 3 – Configurer le serveur RADIUS

Avant de créer le WLAN avec WPA2-Enterprise, le WLC doit connaître l'adresse du serveur RADIUS.

**WLC GUI → Security → New**

| Paramètre | Valeur |
|-----------|--------|
| Server IP Address | `172.31.1.254` |
| Shared Secret | `Cisco123` |

Cliquer **Apply**.

### Étape 4 – Créer le WLAN

**WLC GUI → WLANs → Create New → Go**

| Paramètre | Valeur |
|-----------|--------|
| Profile Name | `Floor 2 Employees` |
| SSID | `SSID-5` |
| ID | `5` |

Cliquer **Apply**, puis dans l'écran d'édition :

| Paramètre | Valeur |
|-----------|--------|
| Status | **Enabled** ✅ *(ne pas oublier !)* |
| Interface | `WLAN-5` |

Onglet **Advanced → FlexConnect** :
- **Local Switching** : activé
- **Local Auth** : activé

Cliquer **Apply**.

### Étape 5 – Configurer la sécurité WPA2-Enterprise

**WLANs Edit → Security → Layer 2**

| Paramètre | Valeur |
|-----------|--------|
| Layer 2 Security | `WPA+WPA2` |
| WPA2 Policy | ✅ Coché |
| Authentication Key Management | `802.1X` *(pas PSK)* |

Onglet **AAA Servers** :
- **Authentication Server 1** → sélectionner le serveur RADIUS configuré (`172.31.1.254`)

Cliquer **Apply**.

## Partie 2 : DHCP Scope et SNMP

### Étape 1 – Vérifier les interfaces du WLC

**WLC GUI → Controller → Interfaces**

**Réponse — quelles interfaces sont présentes ?**  
L'interface **virtual** (interface interne du WLC), l'interface **management** (192.168.200.254), et l'interface **WLAN-5** que nous venons de créer.

**Informations de l'interface management :**
- IP : `192.168.200.254`
- Netmask : `255.255.255.0`
- Gateway : `192.168.200.1`
- Primary DHCP Server : à configurer → `192.168.200.254` (WLC lui-même)

Modifier le **Primary DHCP Server** de l'interface management → `192.168.200.254` → **Apply** → **OK**.

### Étape 2 – Créer un scope DHCP interne

**WLC GUI → Controller → Internal DHCP Server → DHCP Scope → New**

| Paramètre | Valeur |
|-----------|--------|
| Scope Name | `Wired Management` |

Cliquer **Apply**, puis configurer le scope :

| Paramètre | Valeur |
|-----------|--------|
| Pool Start Address | `192.168.200.240` |
| Pool End Address | `192.168.200.249` |
| Network | `192.168.200.0` |
| Netmask | `255.255.255.0` |
| Default Routers | `192.168.200.1` |
| Status | **Enabled** |

Cliquer **Apply** → **Save Configuration** (coin supérieur droit).

> 💡 Après un court délai, LAP-1 reçoit une IP dans `192.168.200.240–249`, le tunnel CAPWAP s'établit, et LAP-1 diffuse `SSID-5`.

### Étape 3 – Configurer SNMP

SNMP (Simple Network Management Protocol) permet au WLC d'envoyer des alertes (traps) à un serveur de supervision.

**WLC GUI → Management → SNMP → Trap Receivers → New**

| Paramètre | Valeur |
|-----------|--------|
| Community String | `WLAN_SNMP` |
| IP Address | `172.31.1.254` |

Cliquer **Apply**.

## Partie 3 : Connecter les hôtes

### Étape 1 – Créer un profil WPA2-Enterprise sur Wireless Host

WPA2-Enterprise nécessite de créer un **profil** dans le client WiFi (contrairement à WPA2-PSK où on entre juste une clé).

**Wireless Host → Desktop → PC Wireless → Profiles → New**

| Étape | Action |
|-------|--------|
| Profile Name | `WLC NET` |
| SSID | Sélectionner `SSID-5` → **Advanced Setup** |
| Network Settings | DHCP (défaut) |
| Security | `WPA2-Enterprise` |
| Login Name | `user1` |
| Password | `User1Pass` |

Cliquer **Save** → sélectionner le profil `WLC NET` → **Connect to Network**.

Après connexion, Wireless Host reçoit une IP via DHCP depuis R-1.

### Étape 2 – Vérifier la connectivité

**Réponse — dans quel réseau l'IP doit-elle être ?**  
`192.168.5.0/24` — car l'interface WLAN-5 du WLC pointe vers le serveur DHCP sur R-1 (`192.168.5.1`), qui a un pool configuré pour ce réseau. Le trafic utilisateur du WLAN est dans VLAN 5.

```
! Wireless Host → Desktop → Command Prompt
ipconfig
! → IP dans 192.168.5.x

ping 192.168.5.1
! → réussit ✅ (gateway R-1)

ping 192.168.200.100
! → réussit ✅ (SW-1)

ping 172.31.1.254
! → réussit ✅ (RADIUS/SNMP Server)
```

## Questions de réflexion

**1. Le serveur RADIUS utilise une double authentification — que sont ces deux choses ?**  
Le RADIUS authentifie **le WLC lui-même** (via le shared secret `Cisco123`) avant de le laisser accéder aux comptes utilisateurs, puis authentifie **l'utilisateur** (via `user1`/`User1Pass`). C'est nécessaire pour s'assurer que seuls les WLCs autorisés peuvent interroger la base de comptes — évite les attaques par un faux WLC.

**2. Avantages de WPA2-Enterprise sur WPA2-PSK :**  
Chaque utilisateur a ses propres identifiants — la compromission d'un compte n'affecte pas les autres. Les accès sont tracés par utilisateur sur le serveur. La révocation d'accès se fait compte par compte sans changer la clé globale. Beaucoup plus adapté aux environnements avec de nombreux utilisateurs.
