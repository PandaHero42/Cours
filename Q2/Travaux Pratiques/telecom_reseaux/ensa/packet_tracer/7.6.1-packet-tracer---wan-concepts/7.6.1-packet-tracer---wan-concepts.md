# Packet Tracer – WAN Concepts

## Objectifs

Explorer différentes technologies WAN utilisées pour connecter des utilisateurs domestiques, mobiles et professionnels aux services de données.

> ℹ️ Lab d'**exploration pure** — pas de configuration, pas de notation. L'objectif est de reconnaître et comprendre les différentes technologies WAN dans une topologie mixte.

---

## Contexte

La topologie présente deux environnements :
- **Consumer WAN** : deux réseaux domestiques connectés via DSL et câble, plus un smartphone
- **Business WAN** : un siège + 3 magasins d'un réseau d'entreprise retail

---

## Partie 1 : Technologies WAN grand public

### Étape 1 : Explorer les réseaux domestiques

**Réponses aux questions :**

**Technologies WAN utilisées dans les réseaux domestiques :**
→ **DSL (Digital Subscriber Line)** pour le premier réseau domestique et **Câble (Cable/DOCSIS)** pour le second.

**Médias et équipements directement connectés à l'ISP :**
→ DSL : ligne téléphonique en cuivre (paire torsadée) → **modem DSL** directement relié à l'ISP/Telco. Câble : câble coaxial → **câble modem** directement relié au réseau câble de l'opérateur.

**Ports et connexions du modem DSL :**
→ Port **Line** (côté ISP — prise téléphonique RJ-11) et port **Ethernet/LAN** (côté réseau domestique). Il peut aussi avoir un port pour le téléphone (voix).

**Rôle du modem DSL :**
→ Convertir le signal numérique Ethernet du réseau domestique en signal DSL transmissible sur la ligne téléphonique en cuivre existante — et inversement pour la réception. Le DSL permet de transporter données et voix simultanément sur la même paire de cuivre.

**Connexion ISP/Câble → réseau domestique, rôle du splitter :**
→ Connexion **coaxiale**. Le **splitter (diviseur de signal)** est nécessaire car le câble coaxial transporte simultanément le signal TV et le signal Internet (sur des fréquences différentes). Le splitter sépare les deux signaux : l'un vers le téléviseur, l'autre vers le câble modem.

**Câble modem — rôle et connexions :**
→ Convertit le signal câble (coaxial DOCSIS) en signal Ethernet pour le réseau domestique. Connexions : port **Coaxial** (vers l'ISP câble) et port **Ethernet** (vers le routeur Wi-Fi domestique).

**Port de connexion sur le routeur Wi-Fi domestique :**
→ Le câble Ethernet du câble modem se branche sur le port **WAN/Internet** du routeur. L'adresse IP de ce port est assignée **par l'ISP via DHCP** (adresse publique dynamique).

**Smartphone — adresse IP et service de données :**
→ Adresse IP obtenue via **DHCP de l'ISP cellulaire** si en données mobiles (4G/LTE), ou via le DHCP du routeur Wi-Fi si connecté en Wi-Fi. Le service de données utilisé est visible dans la config du device (données cellulaires ou Wi-Fi selon la topologie).

### Étape 2 : Explorer le réseau WAN d'entreprise

**Types de connexions dans le réseau Business :**
→ La topologie montre plusieurs types : **Fiber/Fibre optique** pour les liaisons hautes capacités, **Ethernet** pour les liaisons locales, possiblement **liaisons série (WAN)** entre le HQ et l'ISP, et **connexions sans fil** selon la topologie.

**Interfaces présentes sur le switch StoreNet :**
→ Le switch StoreNet dispose d'interfaces **Ethernet** (FastEthernet / GigabitEthernet) pour les connexions LAN locales et d'interfaces **WAN** ou de ports fibre pour les liaisons vers le HQ.

**Interfaces et médias reliant les magasins au Business HQ :**
→ Les magasins sont reliés au HQ via des **liaisons WAN dédiées** (fibre ou liaisons série louées — leased lines). Ce choix est justifié par le besoin de **connectivité permanente, fiable et sécurisée** entre les sites d'une même entreprise, avec une bande passante garantie (SLA).

**Service WAN entre le Business HQ et l'ISP :**
→ Le routeur HQ est connecté à l'ISP via un service **WAN haut débit** (fibre/Ethernet WAN, ou liaison série dédiée selon la topologie). C'est le point de sortie vers Internet pour l'ensemble du réseau d'entreprise.

## Partie 2 : Explorer la connectivité

**Ping entre tous les équipements :**

**Réponse :** **Oui**, tous les hôtes peuvent se pinger mutuellement et atteindre le serveur Web — la connectivité est complète dans cette topologie de démonstration.

**Est-ce une bonne situation ?**

→ **Non, pas entièrement.** En environnement réel, permettre à tous les hôtes de se pinger librement entre réseaux (consumer ↔ business, magasin ↔ HQ sans restriction, réseau domestique ↔ réseau d'entreprise) représente une **faille de sécurité**. Dans un réseau réel, des mesures s'imposent : ACLs pour segmenter et filtrer le trafic inter-réseaux, VPN pour chiffrer les liaisons entre sites d'entreprise, firewall en périphérie, et isolation des réseaux clients des réseaux internes.

## Synthèse — Technologies WAN abordées

| Technologie | Milieu | Débit typique | Cas d'usage |
|-------------|--------|--------------|-------------|
| **DSL** | Paire de cuivre téléphonique | 1–100 Mbps | Résidentiel, petites entreprises |
| **Câble (DOCSIS)** | Câble coaxial | 10–1000 Mbps | Résidentiel, petites entreprises |
| **Fibre optique** | Fibre | 100 Mbps–10+ Gbps | Entreprises, liaisons WAN |
| **Cellulaire (4G/5G)** | Sans fil | 10–1000 Mbps | Mobile, backup WAN |
| **Liaison louée (Leased Line)** | Cuivre/Fibre dédié | Variable | Site-à-site entreprise, SLA garanti |
| **MPLS / Ethernet WAN** | Réseau opérateur | Variable | Réseau d'entreprise multi-sites |

## Mémo — Équipements WAN clés

```
DSL Modem :
  → Côté ISP : prise téléphonique (RJ-11) / ligne cuivre
  → Côté LAN : port Ethernet vers routeur
  → Rôle : convertit Ethernet ↔ signal DSL (modulé sur la paire cuivre)

Câble Modem :
  → Côté ISP : port coaxial
  → Côté LAN : port Ethernet vers routeur Wi-Fi
  → Splitter : sépare signal TV et signal data sur le câble coaxial entrant

Routeur Wi-Fi domestique :
  → Port WAN/Internet : reçoit l'IP publique de l'ISP via DHCP
  → Ports LAN + Wi-Fi : distribue des IP privées via DHCP interne
  → Fait du PAT (NAT Overload) pour partager l'IP publique

WAN d'entreprise multi-sites :
  → Liaisons dédiées (leased line, MPLS) pour SLA et sécurité
  → Souvent combinées avec VPN IPsec sur Internet pour réduire les coûts
  → Séparation claire réseau interne / Internet via firewall/routeur edge
```
