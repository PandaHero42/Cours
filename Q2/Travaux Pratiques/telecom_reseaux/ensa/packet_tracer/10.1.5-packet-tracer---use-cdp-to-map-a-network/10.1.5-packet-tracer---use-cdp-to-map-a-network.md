## Objectifs

- Cartographier un réseau distant en combinant **SSH** (accès distant) et **CDP** (découverte des voisins)

---

## Contexte

**CDP (Cisco Discovery Protocol)** est un protocole propriétaire Cisco opérant à la **couche 2** (Data Link). Il permet à un équipement Cisco de découvrir ses voisins directement connectés, même si ceux-ci n'ont pas d'adresse IP configurée — ce qu'aucun outil de couche 3 (ping, traceroute) ne peut faire.

**Combinaison SSH + CDP :** En se connectant successivement à chaque équipement via SSH et en lançant `show cdp neighbors`, on peut progressivement cartographier l'ensemble d'un réseau sans avoir accès physique aux équipements. C'est la technique de "network discovery" en mode boîte noire.

## Partie 1 : Accès SSH aux équipements réseau

### a–b. SSH depuis Admin-PC vers Edge1

```
PC> ssh -l admin01 192.168.1.1
Password: S3cre7P@55
Edge1#
```

> L'arrivée directe en mode **privileged EXEC** (`#`) sans passer par le mode user (`>`) indique que le compte `admin01` est configuré avec le **niveau de privilège 15** (`privilege level 15`). C'est une pratique courante pour les comptes d'administration.

### c. Documenter les interfaces d'Edge1

```
Edge1# show ip interface brief
Edge1# show interfaces
```

Ces commandes révèlent les adresses IP, masques, et états (up/down) de toutes les interfaces — permettant de compléter les premières lignes du tableau d'adressage.

### d. SSH depuis Edge1 vers Branch-Edge

```
Edge1# ssh -l branchadmin 209.165.200.10
Password: S3cre7P@55
Branch-Edge#
```

**Réponse — information manquante maintenant disponible :** La connexion réussie vers `209.165.200.10` confirme que c'est l'adresse de l'interface S0/0/0 de Branch-Edge (côté ISP/lien WAN). On peut maintenant compléter l'entrée S0/0/1 d'Edge1 dans le tableau.

## Partie 2 : Découverte des voisins via CDP

### a. Documenter les interfaces de Branch-Edge

```
Branch-Edge# show ip interface brief
Branch-Edge# show interfaces
```

Relève les adresses IP et masques de toutes les interfaces de Branch-Edge pour compléter le tableau.

### b–c. Activer CDP et désactiver sur l'interface externe

```
Branch-Edge# show cdp
% CDP is not enabled
```

CDP est désactivé par défaut ou a été coupé. On l'active globalement, puis on le désactive sur l'interface WAN (vers l'ISP) pour des raisons de sécurité :

```
Branch-Edge(config)# cdp run
Branch-Edge(config)# interface s0/0/1
Branch-Edge(config-if)# no cdp enable
```

> **Pourquoi désactiver CDP sur l'interface externe ?** Les paquets CDP contiennent des informations sensibles sur l'équipement (nom, version IOS, plateforme matérielle, adresses IP). Envoyer ces informations vers l'ISP ou Internet expose la topologie interne à des tiers — risque de sécurité. La bonne pratique est : **CDP activé uniquement sur les interfaces internes**, désactivé sur toutes les interfaces exposées à des réseaux non-contrôlés.

### d. Découvrir les voisins immédiats

```
Branch-Edge# show cdp neighbors
```

**Réponse — voisin découvert :** Un switch Cisco est visible (ex. `Branch-S1`), connecté sur l'interface GigabitEthernet ou FastEthernet de Branch-Edge. **L'adresse IP n'est pas listée** dans la sortie de `show cdp neighbors` (vue résumée).

### e. Obtenir les détails du voisin (dont IP)

```
Branch-Edge# show cdp neighbors detail
```

**Réponse — informations supplémentaires sensibles :** En plus de l'adresse IP du voisin, la sortie `detail` révèle :
- La **version IOS** exacte (ex. `Cisco IOS Software, Version 15.x`)
- La **plateforme matérielle** (ex. `cisco WS-C2960`)
- Les **capacités** de l'équipement (Switch, Router, etc.)
- Le **VTP management domain** le cas échéant

> Ces informations sont utiles en diagnostic interne mais constituent une **fuite d'informations** si CDP est activé vers des réseaux non-contrôlés.

### f. SSH vers le switch découvert

```
Branch-Edge# ssh -l branchadmin <IP_du_voisin>
```

**Réponse — prompt affiché :** Le nom du switch découvert (ex. `Branch-S1#`).

### g–h. Cartographie progressive — répéter jusqu'à la fin du réseau

Sur chaque nouvel équipement découvert via SSH :

```
<device># show cdp neighbors
<device># show cdp neighbors detail
```

Puis SSH vers chaque nouveau voisin, documenter ses interfaces et ses propres voisins, jusqu'à atteindre les équipements sans voisins CDP supplémentaires.

**Réponse — switch sans adresse IP :** En fin d'exploration, un switch (ex. `Branch-S3` ou similaire) apparaît dans `show cdp neighbors` d'un voisin mais **ne peut pas être atteint par SSH** (pas d'IP). Son nom est révélé par CDP malgré l'absence d'adresse — c'est la valeur clé de CDP opérant à la couche 2.

## Tableau récapitulatif des commandes clés

| Commande | Contexte | Description |
|----------|----------|-------------|
| `ssh -l <user> <ip>` | PC / Privileged EXEC | Connexion SSH vers un équipement distant |
| `show cdp` | Privileged EXEC | Vérifie si CDP est activé globalement |
| `cdp run` | Global config | Active CDP globalement sur le routeur |
| `no cdp run` | Global config | Désactive CDP globalement |
| `no cdp enable` | Interface config | Désactive CDP sur une interface spécifique |
| `show cdp neighbors` | Privileged EXEC | Liste les voisins CDP directs (résumé : nom, interface, plateforme) |
| `show cdp neighbors detail` | Privileged EXEC | Détails complets (IP, version IOS, plateforme, capacités) |
| `show ip interface brief` | Privileged EXEC | Interfaces et adresses IP en résumé |
| `show interfaces` | Privileged EXEC | Détails complets des interfaces |

## Mémo — CDP

```
CDP = Cisco Discovery Protocol
  → Protocole propriétaire Cisco, couche 2 (Data Link)
  → Fonctionne même sans IP configurée sur l'interface
  → Envoi de "CDP advertisements" toutes les 60 s (holdtime : 180 s)
  → Permet de découvrir : nom, IP, plateforme, version IOS, interfaces

Activation/désactivation :
  cdp run                    ← active globalement
  no cdp run                 ← désactive globalement
  interface <if>
    no cdp enable            ← désactive sur une interface (bonne pratique vers l'extérieur)

show cdp neighbors          → résumé (pas d'IP)
show cdp neighbors detail   → tout (IP, IOS, plateforme) — informations sensibles

Sécurité CDP :
  → Désactiver sur toutes les interfaces exposées à l'extérieur (ISP, DMZ, Wi-Fi public)
  → Activer uniquement sur les interfaces internes de confiance
  → Alternative open-source : LLDP (Link Layer Discovery Protocol, IEEE 802.1AB)
    → compatible multi-vendeurs, commandes : lldp run / show lldp neighbors
```

## Script complet

```
! ============================================================
! PARTIE 1 - Accès SSH
! ============================================================

! --- Depuis Admin-PC ---
ssh -l admin01 192.168.1.1

! --- Sur Edge1 ---
  show ip interface brief
  show interfaces
  ssh -l branchadmin 209.165.200.10

! ============================================================
! PARTIE 2 - Découverte CDP sur Branch-Edge
! ============================================================

! --- Sur Branch-Edge ---
  show cdp

      cdp run
      interface s0/0/1
        no cdp enable

  show cdp neighbors
  show cdp neighbors detail

! SSH vers chaque voisin découvert, puis répéter :
  show cdp neighbors
  show cdp neighbors detail

! Documenter : nom, interface locale, interface distante, IP, masque
! Répéter jusqu'à n'avoir plus de nouveaux voisins
```
