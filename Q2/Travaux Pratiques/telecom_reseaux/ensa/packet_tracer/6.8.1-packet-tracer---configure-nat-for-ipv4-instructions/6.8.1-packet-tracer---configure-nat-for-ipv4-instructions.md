---

## Objectifs

Configurer **uniquement R2** avec :
1. **PAT via pool d'une adresse** pour les 3 LANs internes (`192.168.10.0`, `192.168.20.0`, `192.168.30.0`)
2. **NAT statique** pour rendre `local.pka` accessible depuis Internet

---

## Contexte

Ce lab est un **lab de synthèse NAT** : PAT et NAT statique coexistent sur le même routeur (R2). C'est le scénario le plus réaliste en entreprise — le serveur interne a une IP publique fixe (NAT statique), tandis que les postes clients partagent une IP publique via PAT.

**Contraintes de nommage (sensibles à la casse) :**
- ACL : `R2NAT`
- Pool : `R2POOL`

---

## Configuration complète de R2

### Étape 1 : ACL standard nommée `R2NAT`

```
R2(config)# ip access-list standard R2NAT
R2(config-std-nacl)# permit 192.168.10.0 0.0.0.255
R2(config-std-nacl)# permit 192.168.20.0 0.0.0.255
R2(config-std-nacl)# permit 192.168.30.0 0.0.0.255
```

**Ordre des ACEs :** LAN1 → LAN2 → LAN3, conformément aux instructions. L'ordre est imposé pour la notation automatique dans Packet Tracer.

> **Pourquoi `192.168.20.0/24` (LAN2) est dans l'ACL PAT ET a une entrée statique ?** L'ACL PAT couvre l'ensemble du LAN2, dont `local.pka`. Cependant, la règle de NAT statique (`ip nat inside source static`) a **priorité** sur la règle PAT pour l'hôte `192.168.20.254` — IOS évalue d'abord les règles statiques. `local.pka` sera donc toujours traduit en `.130`, pas en `.129`.

### Étape 2 : Pool NAT `R2POOL` (une seule adresse)

```
R2(config)# ip nat pool R2POOL 209.165.202.129 209.165.202.129 netmask 255.255.255.252
```

> **Pool d'une seule adresse** (`209.165.202.129` à `209.165.202.129`) : début et fin identiques. Combiné avec `overload`, cette unique adresse publique sert toutes les sessions PAT. `.130` est réservée au NAT statique.

### Étape 3 : Associer ACL + pool + activer PAT

```
R2(config)# ip nat inside source list R2NAT pool R2POOL overload
```

> ACL nommée → on utilise le **nom** (`R2NAT`) à la place du numéro dans la commande. La syntaxe est identique.

### Étape 4 : NAT statique pour `local.pka`

```
R2(config)# ip nat inside source static 192.168.20.254 209.165.202.130
```

> `192.168.20.254` (adresse privée Inside Local de `local.pka`) ↔ `209.165.202.130` (adresse publique Inside Global). Entrée permanente et bidirectionnelle — les hôtes externes peuvent accéder à `local.pka` via `209.165.202.130`.

### Étape 5 : Configurer les interfaces NAT

```
R2(config)# interface FastEthernet0/0/0
R2(config-if)# ip nat inside

R2(config)# interface Serial0/0/0
R2(config-if)# ip nat inside

R2(config)# interface Serial0/0/1
R2(config-if)# ip nat inside

R2(config)# interface Serial0/1/0
R2(config-if)# ip nat outside
```

> R2 a **3 interfaces inside** : F0/0/0 (LAN2 direct), S0/0/0 (lien vers R1/LAN1), S0/0/1 (lien vers R3/LAN3). Le trafic de LAN1 et LAN3 transite par les interfaces série vers R2 avant d'être traduit. Sans `ip nat inside` sur ces interfaces série, le trafic de PC1 et PC2 ne serait pas traduit.

## Configuration complète (answer key)

```
R2# enable
R2# configure terminal

interface FastEthernet0/0/0
 ip nat inside

interface Serial0/0/0
 ip nat inside

interface Serial0/0/1
 ip nat inside

interface Serial0/1/0
 ip nat outside

ip nat pool R2POOL 209.165.202.129 209.165.202.129 netmask 255.255.255.252
ip nat inside source list R2NAT pool R2POOL overload
ip nat inside source static 192.168.20.254 209.165.202.130

ip access-list standard R2NAT
 permit 192.168.10.0 0.0.0.255
 permit 192.168.20.0 0.0.0.255
 permit 192.168.30.0 0.0.0.255

end
```

## Tableau récapitulatif des commandes clés

| Commande | Contexte | Description |
|----------|----------|-------------|
| `ip access-list standard <nom>` | Global config | ACL standard nommée (sélection hôtes à traduire) |
| `ip nat pool <nom> <ip> <ip> netmask <masque>` | Global config | Pool NAT (peut être une seule IP) |
| `ip nat inside source list <nom_acl> pool <nom_pool> overload` | Global config | PAT avec ACL nommée et pool |
| `ip nat inside source static <local> <global>` | Global config | NAT statique permanent |
| `ip nat inside` | Interface config | Marque l'interface inside |
| `ip nat outside` | Interface config | Marque l'interface outside |
| `show ip nat translations` | Privileged EXEC | Vérifie les traductions (statiques + dynamiques) |
| `show ip nat statistics` | Privileged EXEC | Vue d'ensemble du NAT |

## Mémo — Coexistence NAT statique + PAT

```
Sur un même routeur, NAT statique et PAT coexistent sans conflit :

  PAT (dynamique) : ip nat inside source list R2NAT pool R2POOL overload
    → S'applique à tous les hôtes matchant R2NAT
    → Traduit vers 209.165.202.129 (+ port)

  Statique : ip nat inside source static 192.168.20.254 209.165.202.130
    → Priorité sur PAT pour l'hôte 192.168.20.254
    → Traduit toujours vers 209.165.202.130 (fixe, bidirectionnel)

Priorité d'évaluation IOS :
  1. NAT statique (entrées fixes dans la table)
  2. NAT dynamique / PAT (entrées générées à la demande)

Pool d'une seule adresse + overload = PAT pur
  ip nat pool R2POOL 209.165.202.129 209.165.202.129 netmask 255.255.255.252
  → Identique à "interface overload" mais avec un nom de pool
```

## Script complet

```
! ============================================================
! Configuration NAT complète sur R2
! ============================================================

! --- Interfaces ---
      interface FastEthernet0/0/0
        ip nat inside

      interface Serial0/0/0
        ip nat inside

      interface Serial0/0/1
        ip nat inside

      interface Serial0/1/0
        ip nat outside

! --- Pool PAT (une seule adresse publique) ---
      ip nat pool R2POOL 209.165.202.129 209.165.202.129 netmask 255.255.255.252

! --- PAT : ACL nommée + pool + overload ---
      ip nat inside source list R2NAT pool R2POOL overload

! --- NAT statique : local.pka accessible depuis Internet ---
      ip nat inside source static 192.168.20.254 209.165.202.130

! --- ACL R2NAT : 3 LANs internes (ordre imposé) ---
      ip access-list standard R2NAT
        permit 192.168.10.0 0.0.0.255
        permit 192.168.20.0 0.0.0.255
        permit 192.168.30.0 0.0.0.255

! ============================================================
! Vérification
! ============================================================

  show ip nat translations
  show ip nat statistics
  show run | include nat
```
